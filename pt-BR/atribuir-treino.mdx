---
title: "Atribuir um treino a um aluno ou time"
description: "Envie um treino pronto para uma pessoa ou para um time inteiro de uma vez."
---

Depois de montar um treino, é hora de colocá-lo na mão do aluno. Você pode atribuir
para uma pessoa específica ou para um time inteiro de uma só vez.

## Como atribuir

<Steps>
  <Step title="Escolha o treino">
    Em **Treinos**, encontre o treino que você quer enviar.
  </Step>
  <Step title="Atribua para quem vai treinar">
    Use a opção de **atribuir** e escolha o destino: um aluno específico ou um time
    inteiro.
  </Step>
  <Step title="Confirme">
    Pronto. O treino aparece no aplicativo do aluno, pronto para ele executar.
  </Step>
</Steps>

<Tip>
  Atribuir para um **time** é o jeito mais rápido de mandar o mesmo treino para várias
  pessoas ao mesmo tempo.
</Tip>

<Note>
  Conforme o aluno treina, as conclusões dele voltam para você — dá para acompanhar o
  que foi feito no perfil da pessoa.
</Note>
