---
title: "Atribuir treinos a um atleta ou time"
description: "Entregue uma pasta de treinos para uma pessoa, para vários atletas ou para um time inteiro."
---

Os treinos são entregues por **pasta**: você escolhe uma pasta e a manda para quem vai
treinar. Assim, todos os treinos daquela pasta chegam de uma vez na conta do atleta.

## Atribuir uma pasta a um atleta

<Steps>
  <Step title="Abra o atleta">
    Em **Atletas**, abra a pessoa que vai receber os treinos.
  </Step>
  <Step title="Escolha a pasta">
    Selecione a **pasta** com os treinos que você quer entregar.
  </Step>
  <Step title="Escolha como entregar">
    - **Atribuir pasta** — entrega os treinos da pasta para o atleta. Ele recebe e treina;
      você continua dono dos treinos.
    - **Copiar pasta** — cria cópias exclusivas para esse atleta. Você pode ajustar esses
      treinos só para ele, sem mexer nos seus originais.
  </Step>
  <Step title="Confirme">
    Pronto. Os treinos aparecem no aplicativo do atleta, prontos para ele executar.
  </Step>
</Steps>

<Tip>
  Use **Atribuir pasta** quando o mesmo plano serve para várias pessoas. Use **Copiar
  pasta** quando quiser personalizar os treinos para aquele atleta específico.
</Tip>

## Atribuir para um time ou vários atletas

Para mandar os mesmos treinos para muita gente de uma vez, também é por pasta:

<Steps>
  <Step title="Escolha a pasta">
    Na sua biblioteca de **Treinos**, encontre a pasta que quer enviar.
  </Step>
  <Step title="Use Atribuir pasta">
    No menu de opções (⋯) da pasta, escolha **Atribuir pasta** e selecione o destino: um
    **time** inteiro ou **vários atletas** de uma vez.
  </Step>
  <Step title="Confirme">
    Todos recebem os treinos da pasta no aplicativo, de uma só vez.
  </Step>
</Steps>

<Tip>
  Atribuir uma pasta a um **time** é o jeito mais rápido de mandar o mesmo plano para
  várias pessoas ao mesmo tempo.
</Tip>

## Compartilhar uma pasta por link

Quer entregar uma pasta para alguém que **não** está na sua lista? Use o menu de opções (⋯)
da pasta e escolha **Compartilhar**: quem abre o link copia os treinos para a conta dele.

Veja o passo a passo em [compartilhar treinos por link](/pt-BR/compartilhar-treino-link).

<Note>
  Conforme o atleta treina, as conclusões dele voltam para você — dá para acompanhar o
  que foi feito no perfil da pessoa.
</Note>
