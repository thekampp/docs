Atribuir uma pasta a um **time** é entregar para todo mundo de uma vez — inclusive para
quem entrar depois. É o mural do time: quem está lá, recebe.

## Atribuir uma pasta ao time

<Steps>
  <Step title="Abra o time">
    Em **Times**, clique no time e vá no bloco **Treinos do time**.
  </Step>
  <Step title="Clique em Atribuir pasta">
    Escolha a pasta com os treinos que o time vai receber.
  </Step>
  <Step title="Defina quem recebe">
    Use os filtros (abaixo) para direcionar a entrega, ou deixe tudo em **Indiferente**
    para todo mundo receber.
  </Step>
  <Step title="Agende (opcional)">
    Defina quando os treinos ficam disponíveis e por quantas semanas.
  </Step>
</Steps>

## Filtros: entregando o treino certo

Você pode atribuir várias pastas ao mesmo time, cada uma para um perfil diferente. Três
filtros decidem quem recebe cada uma:

### Este treino é para?

**Indiferente**, **Masculino** ou **Feminino**.

### Onde o atleta treina?

**Indiferente**, **Em casa**, **Academia** ou **Misto**. Quem ainda não informou onde
treina recebe assim que preencher o perfil.

### Qual o objetivo do atleta

Aqui tem uma diferença importante entre três opções:

- **Indiferente** — todos recebem, seja qual for o objetivo. **Soma** com as pastas de
  objetivo específico (quem quer hipertrofia recebe a pasta "Indiferente" **e** a de
  hipertrofia). Use para a base que vale para todo mundo.
- **Um objetivo específico** (Hipertrofia, Emagrecimento, Força…) — só quem marcou aquele
  objetivo no app recebe.
- **Padrão · todos os outros** — a rede de segurança: recebe quem **não** se encaixou em
  nenhum objetivo específico daquele time. Nunca vem junto com um específico.

<Tip>
  A receita que funciona: uma pasta **Indiferente** com o essencial (mobilidade, core),
  pastas específicas para os objetivos que você atende e uma pasta **Padrão · todos os
  outros** para não deixar ninguém sem treino.
</Tip>

## Quando o treino aparece

No agendamento você escolhe entre liberar na hora, numa data marcada ou um tempo depois de
a pessoa entrar no time. Essa última é a mais usada em turmas: cada atleta começa a
contar do dia em que entrou, não do dia em que você montou.

## Dietas do time

O bloco **Dietas do time** funciona da mesma forma: **Atribuir dieta** entrega o plano
para todo o grupo. Veja [entregar uma dieta](/pt-BR/atribuir-dieta).

<Note>
  Quem entra no time depois recebe automaticamente o que está no mural — não precisa
  atribuir de novo.
</Note>
