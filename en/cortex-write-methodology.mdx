The **Your methodology** field is usually where everyone freezes. You know how to
prescribe — you've just never had to **write down** how you prescribe.

That's what the **Don't know where to start?** card is for, in the **My Coach DNA** tab,
right below "What do you prescribe?".

## How it works

<Steps>
  <Step title="Copy the prompt">
    Click **Copy prompt**. If you'd rather see it first, use **View the prompt** to open the
    full text.
  </Step>
  <Step title="Paste it into the AI you use">
    Open the AI assistant you already use day to day and paste the text in.
  </Step>
  <Step title="Answer like you would a colleague">
    It interviews you in rounds of a few questions. Answer in your own words, with no
    formality — it's a conversation, not a form.
  </Step>
  <Step title="Paste in workouts and diets, if you have them handy">
    When it asks, you can paste in prescriptions you've already written. It's **optional**,
    but it helps a lot: it reads your pattern in what you've already delivered.
  </Step>
  <Step title="Bring the five blocks back">
    At the end, it hands the text back split into five blocks, in the same order as the
    fields on the screen. Paste each one into the matching Coach DNA field.
  </Step>
</Steps>

The blocks come named like this:

```
===== METHODOLOGY =====
===== WORKOUT GUIDELINES =====
===== DIET GUIDELINES =====
===== RULES AND THINGS TO AVOID =====
===== COMMUNICATION TONE =====
```

Each one goes into the field with the same name in **My Coach DNA**.

## What to expect from the interview

- It takes roughly **10 minutes**.
- It **doesn't make up** what you didn't say. When something isn't clear, it records it as
  "not defined" instead of filling it in on its own.
- Every round it shows a confidence line per block, so you can see what's still thin.
- It only hands over the result once the five blocks are well covered — or when you write
  **"go ahead and deliver"**.

<Tip>
  Don't accept the first result on autopilot. **Read it and cut whatever isn't you.** The
  value of Coach DNA is precisely in what's yours; generic text that slips through turns
  into generic suggestions later.
</Tip>

<Note>
  If the copy button doesn't work (some browsers block it), Kampp opens the prompt for you
  so you can select and copy it by hand.
</Note>

## After you paste

Go back to [Coach DNA](/en/cortex-coach-dna), review the five fields, check the **Diet
targets** and click **Activate Coach DNA**.
