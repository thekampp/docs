---
title: "Import workouts from a spreadsheet"
description: "Already have workouts in a spreadsheet? Upload the file and Kampp builds it all for you."
---

If you already organize your workouts in a spreadsheet, there's no need to retype
anything. Download our template, fill it in (or paste your data into it), and upload —
Kampp reads the spreadsheet and creates the workouts ready to go.

## How to import

<Steps>
  <Step title="Open the import option">
    In the **Workouts** area, on the **new workout** button, choose **Import from
    spreadsheet**.
  </Step>
  <Step title="Download the template">
    Click **Download template (.xlsx)**. Use this template so the columns are exactly
    how Kampp understands them.
  </Step>
  <Step title="Fill in the spreadsheet">
    Each **row is an exercise**. Exercises with the same **workout name** are grouped
    into the same workout. The main columns are:
    - **Workout** — the workout name (e.g., "Workout A - Lower body")
    - **Exercise** — the movement (e.g., "Squat")
    - **Sets**, **Reps**, and **Load (kg)**
    - **Instructions** for the exercise (optional, e.g., "tempo 3-0-3")
  </Step>
  <Step title="Upload the file and review">
    Select the filled-in spreadsheet. Kampp shows a preview of the workouts it will
    create so you can review before confirming.
  </Step>
  <Step title="Import">
    Confirm. The workouts are created and ready for you to assign to clients.
  </Step>
</Steps>

<Tip>
  Want to migrate an old spreadsheet of yours? Copy the data into our template, keeping
  the column names — that way the reading comes out right.
</Tip>

<Note>
  We accept **.xlsx** files (and .csv too). Rows without a workout name or exercise are
  ignored, so don't worry about a blank line here or there.
</Note>
