title: "Set types and per-exercise notes"
description: "Mark warm-up, failure and drop sets, use rep ranges and leave a message for the athlete on each exercise."
---

All of this lives in the **exercise settings modal** — the sliders icon on the exercise card,
inside the builder.

## The exercise mode

At the top, the pills define what the athlete records:

- **Weight + Reps** — the most common one, weight training.
- **Reps** — bodyweight.
- **Time** — planks, isometrics, bike.
- **Distance** — running, rowing.

## Set types

Click the set number (the **SET** column) and choose:

| Type | Mark | When to use it |
| --- | --- | --- |
| **Warm-up** | **W** (amber) | Ramp-up sets, before the ones that count. |
| **Normal** | • | The working set. |
| **Failure** | **F** (red) | When you want them to take it to failure. |
| **Drop** | **D** (blue) | Drop set. |

<Tip>
  Set numbering **counts only the normal ones**. A warm-up set doesn't "use up" a number — so
  what the athlete calls "set 1" is the first set that counts, just like you'd say it in the
  gym.
</Tip>

## Rep range

The reps field takes a fixed value (`12`) **or a range** (`10-12`). Just type the two numbers
and the dash appears on its own.

Use a range when you want to leave room for self-regulation, and a fixed number when
execution has to be exact.

## Fill everything in at once

On the first row there's the **Apply to all sets** arrow: it copies the weight and reps from
that set to all the others. Then you just adjust the exceptions.

Every exercise starts with **3 sets**. Use **Add Set** for more, and the trash icon to remove
one (the last one can't be deleted).

## Rest

A field from 0 to 999 seconds, with **−** and **+** buttons (in steps of 5) and ready-made
shortcuts: **No rest, 30s, 45s, 1m, 2m, 3m, 5m**. At zero, the app shows "No rest".

## Notes: your message on the exercise

In the **Notes** field you write the guidance for that exercise, up to 1000 characters.

> *E.g.: Lower slowly, 3s on the way down. Don't lock the elbow at the top.*

**This note shows up for the athlete in the app, inside that exercise** — it isn't an internal
note. It's the right place for tempo, range of motion, grip, posture and whatever else you'd
correct in person.

<Note>
  Don't confuse it with [athlete notes](/en/athlete-notes), which are private and nobody
  besides you (and your staff) sees.
</Note>

<Tip>
  This is where a good chunk of the difference between a spreadsheet and real coaching lives.
  A workout with notes on the key exercises is worth more than a workout with ten extra
  exercises.
</Tip>
