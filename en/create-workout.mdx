The workout is the heart of your work. Here you build the sequence of exercises with the
sets, reps and loads, and choose which folder it's saved in.

## Before you start: the library tabs

In the **Workouts** menu, the screen has tabs:

- **My Library** — your workouts.
- **Blocks** — the warm-up, mobility and stretching sequences that go with the workouts.
  See [Blocks](/en/blocks-before-after).

The red button at the top changes name depending on the tab you're on: **Create Workout** or
**Create Block**.

## How to build one

<Steps>
  <Step title="Click Create Workout">
    Kampp asks how you want to start:

    - **Create from scratch** — build it in the builder, exercise by exercise.
    - **Import from a spreadsheet** — upload one or several workouts at once. See
      [Import workouts from a spreadsheet](/en/import-workouts-spreadsheet).
  </Step>
  <Step title="Name it and choose the folder">
    Name the workout (e.g., "Workout A - Lower body") and choose the **folder**. If you don't
    pick one, it goes to the default folder **My Workouts** — which in the library listing
    shows up as the **My programs** group.
  </Step>
  <Step title="Add a cover (optional)">
    The background image of the card in the athlete's app. See
    [Workout cover](/en/workout-cover).
  </Step>
  <Step title="Add an instructions video (optional)">
    Turn on the **Instructions video** switch and upload an **MP4, MOV or WebM** file of up to
    **80 MB**. It shows up above the description on the workout screen.
  </Step>
  <Step title="Choose the format">
    Right above the exercise list: **Classic workout** (exercise by exercise) or **Rounds
    workout** (circuit).

    The gear icon in each round's header sets two things:

    - **Round name** — e.g. "Warm-up", "Main block", "Finisher". Without a name, it shows up
      as "Round 1", "Round 2" and so on.
    - **Rest after the round** — how long the athlete rests before starting the next one.

    The rest belongs to **each round**, not to the whole workout: you can run the warm-up
    straight through (zero) and give the heavy block two minutes.

    To repeat a whole round with the same exercises, use the **duplicate** icon in its
    header — the copy lands right below it and you tweak whatever you need.
  </Step>
  <Step title="Add the exercises">
    Search the library and build the list. Each exercise starts with **3 sets**.
  </Step>
  <Step title="Set up each exercise">
    Click the exercise's controls icon to set sets, reps, load, rest and your note. See
    [Set types and notes](/en/set-types-and-notes).
  </Step>
  <Step title="Attach blocks (optional)">
    In the **Before and after** section, add the warm-up and the cool-down. See
    [Blocks](/en/blocks-before-after).
  </Step>
  <Step title="Save">
    The workout stays in your library, ready to be assigned as many times as you want.
  </Step>
</Steps>

## Kampp won't let you lose work

- **Automatic draft.** If you close the tab in the middle of building and come back later,
  Kampp tells you: *Draft recovered — picking up where you left off.* Use **Discard** if
  you'd rather start over.
- **Warning on exit.** Tried to leave with unsaved changes? It asks first, with the options
  to keep editing, save and leave, or discard.
- **Check before saving.** If something is missing (a set without reps, for example), Kampp
  lists item by item what needs to be filled in.

## Create a workout straight for one athlete

When you open the builder from inside an athlete's profile, the screen changes: the title
becomes **New workout for [Name]** and their training profile stays visible on the side
while you build.

That workout is born exclusive to that person — editing it later doesn't affect anyone else.

<Tip>
  Want to create the workout right inside a specific folder? Open the folder's options menu
  (⋯) in your library and use **New workout in folder** — it's born in the right place.
</Tip>

<Note>
  Can't find an exercise? You can add your own to the library — see

</Note>
